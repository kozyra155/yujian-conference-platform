# 遇见科技统一界面

用户已要求直接优化会议目录、创建会议、个人工作台，并以 EAAMS 站为参考改善体验会议网站。本轮沿用这项授权实施，不增加设计审批步骤。

采用 Vue 3、Element Plus 的本地构建组件，覆盖 `/category/1/`、`/conference/create/`、`/user/dashboard/`、`/organizer/`、`/conference/<id>/`。后台采用白色顶栏、深蓝侧栏、浅灰内容区，中文优先，同时支持现有英文切换。目录显示实际公开会议，个人工作台显示自己的会议，发布操作保留确认和私密草稿规则。原生内容编辑与个人设置保留其成熟业务逻辑，统一外观并提供清楚的返回入口。原生参会记录仍可访问。

会议网站采用 1200px 居中版心、蓝色科学主题横幅、横向栏目导航、白色正文和右侧重要日期/快捷链接栏，使用现有会议日期、地点、栏目与内容，不编造投稿截止日期、委员会或联系方式。移动端纵向排列，长标题可换行；英文切换翻译界面，不自动翻译主办方内容。保留原生页面 ACL、HTML 清洗和自定义首页，主题预览不被覆盖。

验收：两个用户指定入口不再呈现原始界面；组件本地提供；登录状态正确；创建、编辑、发布、撤回闭环仍通过；320/390/760/1440px 无横向溢出；公开页和私密栏目遵守既有权限。
