# 会议栏目编辑工作台

用户要求直接优化 `/event/22/manage/layout/menu/`，沿用已授权的遇见科技 Vue 3 + Element Plus 工作台方向。颜色使用深蓝 #193c57、操作蓝 #246b9b、正文 #233b51、浅底 #f3f6fa、边框 #e3eaf1、状态绿 #26856e；中文系统无衬线字体，标题 25px、正文 13px。左侧站点导航、顶部会议信息和预览入口，主体宽列表及窄帮助栏，操作左对齐。重点是主办方栏目和操作含义，减少原生会务菜单带来的干扰。

使用 Element Plus 搜索、筛选、添加菜单；原生列表与富文本对话框保留，以保全图片上传、ACL、CSRF、嵌套、拖拽和锁定处理。默认筛选网站页面及链接，另可查看会务功能或全部；过滤只隐藏列表项，不改变菜单配置。排序仅在“全部栏目”且没有搜索时启用，避免过滤后的隐藏项造成顺序歧义。列表标明类型、显示状态、首页设置，编辑动作有文字。菜单模式重置操作保留在高级设置中，继续使用原生删除确认。

只读查看会议 22，不用其真实内容做测试。功能验收使用临时会议，最终清理；验证新增、富文本保存、可见性、首页设置、排序和跨账号拒绝。320/390/760/1440px 无横向溢出，移动端保留操作和导航。

用户随后增加 `/user/profile/` 和 `/user/dashboard/?legacy=1`，一并使用共享工作台外壳。个人资料保留原生 React 表单与账号设置入口，常用设置改为紧凑标签，扩展设置放在更多菜单；仅当前用户页面替换外壳，管理员查看他人资料仍用原生页面。参会记录保留原生关联会议、角色、关注目录及日历组件。语言同步完成后仅在没有编辑输入或打开对话框时刷新原生个人页面，保护未保存信息。
