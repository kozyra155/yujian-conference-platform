# 遇见科技一键建站验收

日期：2026-10-14。环境：本地 `yujian-indico-v1`，Indico 3.3.13，`http://localhost:12880/`。

## 使用流程

1. 在 `/register/` 注册并完成原生邮箱验证，或登录已有账号。
2. 打开 `/conference/create/`，填写名称、开始结束时间、地点、简介，选择学术蓝或科技绿模板。
3. 系统在同一事务内创建会议及六个栏目：委员会、主题、日程、地点、通知、联系。初始为私密草稿。
4. 在网站工作台进入原生栏目编辑器，保存内容并预览。
5. 发布后，会议网址公开，且自动出现在首页与活动页的平台会议区域。
6. 撤回后，公开列表移除会议，网页、附件和导出恢复草稿权限。内容保留，可再次发布。

入口：[创建网站](http://localhost:12880/conference/create/)、[我的会议](http://localhost:12880/organizer/)、[体验网站](http://localhost:12880/event/4/)。体验网站由 host-a 管理，明确标注为演示，不接受真实报名。

## 实现

自有扩展位于 `indico-demo/worker/extension/yujian_site/`，通过标准 Indico 插件入口加载；未改动上游源码。使用原有账号、数据库、CSRF、会议 ACL、内容编辑器和事务。建站入口对有效登录账号授予平台目录的创建权限，不授予全局或目录管理权限。

`portal/builder.*` 提供创建与发布工作台；`public-conferences.js` 连接真实会议接口，支持标题、地点查询和分页。历史 15 场线上宣讲会及其原始链接、地区和时区功能保留。

两场原有演示会议已纳入工作台，仅补充原先缺失的地点和管理状态，原有内容、主办方和配色保留。初始化脚本适配新扩展，新环境中的演示会议仍会完整生成并公开。

## 验证结果

| 检查 | 结果与证据 |
| --- | --- |
| 原生注册接口 | 使用测试签名邮件链接验证邮箱后，提交原生注册接口成功；无效签名被拒绝。测试进程使用内存邮件后端，不向外发信 |
| 普通账号建站 | 新注册的非管理员账号成功创建；只有平台目录创建权，没有目录管理权 |
| 自动栏目 | 六个栏目生成，重复调用初始化不重复添加 |
| 输入校验 | 日期顺序、非法分页、极大分页均被拒绝；简介 HTML 作为文本处理 |
| 会话与 CSRF | 未携带 CSRF 的发布请求被拒绝；两个账号之间的管理请求返回 403 |
| 草稿预览 | 主办方可预览，匿名用户被拦截；单独授予只读 ACL 也无法打开草稿 |
| 原生编辑器 | 浏览器实际编辑并保存委员会内容，发布后匿名读取到保存的文字 |
| 发布与查询 | 公开网页返回 200；首页和活动页自动出现；按武汉地点搜索可找到体验会议 |
| 撤回 | 网站不再公开，动态列表移除；再次发布恢复可访问 |
| 原生导出 | 修复旧版导出缓存先于权限检查的问题，撤回后相同导出 URL 不再返回会议内容 |
| 附件权限 | 单独授权的保护附件链接在发布时可访问、撤回后 403；旧版文件导出先检查网站草稿状态，不能由资源角色绕过 |
| 会议锁定 | 锁定会议不能通过新增接口发布，返回 403 |
| 注册语言切换 | 已填写的邮箱、姓名和密码在切换中英文时保留；不将输入保存到 localStorage |
| 创建入口 | 首页创建标记在首次进入和同页面跳转时均转向建站表单 |
| SMTP | 布尔开关严格校验，字符串、数字、空值及缺失开关报错；4 项单元测试通过 |
| 响应式 | 建站页、发布工作台、生成网站首页及栏目页在 320、390、760、1440px 无横向溢出 |
| 原有页面回归 | 首页导航搜索、历史活动筛选、会话及中英文、品牌登录、注册表单通过；浏览器未记录页面脚本异常 |

后端测试为 `indico-demo/verify_site_builder.py`，完成后将临时账号、会议标记删除；浏览器测试 `verify_builder_browser.cjs` 复用唯一体验会议并保留公开供验收。

## 边界

- 实际验证码邮件收件仍未验收。自动测试使用测试签名链接及进程内邮件后端；这证明注册接口与后续建站相连，不证明外部邮箱已收到邮件。
- 当前网址仅供本机访问。公网域名、HTTPS 和正式部署尚未验收。
- 发布使用同一份内容，保存编辑即时影响公开网站；需要私密修改时先撤回。没有独立内容版本或子域名。
- 支付、报名、投稿审稿不在本轮网站生成流程内，未将这些业务标记为已验收。
- 原生旧版数据导出不使用结果缓存，保证撤回后的即时权限检查；尚未进行高并发导出及压力测试。从零重建完整镜像也未重新验收。
